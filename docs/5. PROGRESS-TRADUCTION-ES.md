## 📝 NOTES TECHNIQUES

### Fichiers à modifier :
- `frontend/public/index.html` (tous les textes dans le HTML + JS inline)

### Approche recommandée :
1. **Rechercher tous les textes FR** : Ctrl+F dans VS Code
2. **Traduire section par section** (Header → Carte → Formulaire → Footer)
3. **Cocher au fur et à mesure** dans ce PROGRESS
4. **Tester régulièrement** (après chaque section majeure)

### Points d'attention :
- ⚠️ **Accents espagnols** : Bien utiliser á, é, í, ó, ú, ñ
- ⚠️ **Longueur des textes** : Espagnol parfois + long → vérifier mise en page
- ⚠️ **Console logs** : Traduire aussi pour cohérence (même si invisible pour utilisateur)
- ⚠️ **Commentaires code** : Peuvent rester en FR (pour développeur) ou traduire en ES
