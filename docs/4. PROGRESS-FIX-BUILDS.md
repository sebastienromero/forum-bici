### ⬜ ÉTAPE 5 : Correction du problème (15-30 min)

**Objectif :** Corriger la cause racine identifiée

#### 5A : Si problème = fichiers public/ dans Git (20 min)

**Diagnostic :** `public/css`, `public/config`, `public/data` sont versionnés → boucle infinie

**Solution :**
- [ ] 5A.1 - Supprimer fichiers du tracking Git :
  ```bash
  cd frontend
  git rm -r --cached public/css public/config public/data
  ```

- [ ] 5A.2 - Vérifier/corriger `.gitignore` :
  ```bash
  echo "# Generated files (do not commit)" >> .gitignore
  echo "public/css/" >> .gitignore
  echo "public/config/" >> .gitignore
  echo "public/data/" >> .gitignore
  ```

- [ ] 5A.3 - Commit la correction :
  ```bash
  git add .gitignore
  git commit -m "fix(build): exclude generated public/ files from Git"
  ```

- [ ] 5A.4 - Vérifier :
  ```bash
  git status
  # Ne doit PAS montrer public/css, public/config, public/data
  ```

- [ ] 5A.5 - Push :
  ```bash
  git push origin TEST-MVP
  ```

**Résultat attendu :** Prochains builds ne généreront plus de commits automatiques ✅
