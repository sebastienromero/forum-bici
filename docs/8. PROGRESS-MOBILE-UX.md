**Créé le:** 2025-01-XX

**Objectif:** Optimiser l'expérience utilisateur sur mobile (<768px)

## 📊 ÉTAT ACTUEL

### Responsive Design Actuel
- ✅ **1 media query trouvée** : Tablettes (769px - 1024px)
- ❌ **Aucune media query mobile** : <768px non optimisé
- ⚠️ **Conséquence** : Le site applique les styles desktop sur mobile

```css
/* Ligne 837 - SEULE media query existante */
@media (min-width: 769px) and (max-width: 1024px) {
    #rating-panel { max-width: 500px; }
    .nav-btn { font-size: 14px; padding: 8px 14px; }
}
```

## 🚨 PROBLÈMES IDENTIFIÉS

### P0 - CRITIQUES (bloquants UX mobile)

#### 1. **HEADER - Débordement horizontal**
**Problème:**
- Header fixe : 60px de hauteur
- Contenu : Logo + 5 boutons nav + sélecteur langue (2 boutons) + bouton thème
- Total : ~9 éléments sur une ligne avec `display: flex`
- Sur iPhone (375px) : **IMPOSSIBLE de tout afficher**

**Impact:**
- Navigation inaccessible
- Boutons coupés ou invisibles
- Scroll horizontal dans le header

**Solution recommandée:**
```css
@media (max-width: 768px) {
    header {
        height: auto; /* Hauteur flexible */
        flex-direction: column;
        padding: 1rem;
        gap: 1rem;
    }
    
    nav {
        width: 100%;
        flex-wrap: wrap;
        justify-content: center;
    }
    
    nav button {
        flex: 1 1 calc(50% - 0.5rem); /* 2 colonnes */
        min-width: 120px;
    }
}
```

**Alternative (hamburger menu):**
```css
@media (max-width: 768px) {
    nav {
        position: fixed;
        top: 60px;
        left: -100%;
        width: 80%;
        height: calc(100vh - 60px);
        background: var(--header-bg);
        flex-direction: column;
        transition: left 0.3s;
        box-shadow: 2px 0 8px rgba(0,0,0,0.2);
    }
    
    nav.open { left: 0; }
    
    .hamburger {
        display: block; /* Ajouter bouton hamburger */
    }
}
```

#### 2. **NAVIGATION - Boutons trop petits pour touch**
**Problème:**
- Taille actuelle : padding 0.4rem 0.9rem ≈ 35px de hauteur
- Standard tactile minimum : **44x44px** (Apple HIG & Material Design)
- Font-size : 0.9rem (14.4px) trop petit

**Impact:**
- Difficile de cliquer précisément
- Frustration utilisateur
- Erreurs de navigation

**Solution:**
```css
@media (max-width: 768px) {
    nav button {
        padding: 12px 16px; /* ≥44px hauteur */
        font-size: 16px; /* Lisibilité mobile */
        min-height: 44px;
        min-width: 44px;
    }
}
```

#### 3. **SÉLECTEUR DE LANGUE - Touch targets trop petits**
**Problème:**
- Boutons actuels : padding 6px 12px ≈ 30px hauteur
- Font-size : 13px
- Sous le minimum tactile (44px)

**Impact:**
- Difficile de changer de langue
- Clics ratés fréquents

**Solution:**
```css
@media (max-width: 768px) {
    .language-selector {
        gap: 12px;
    }
    
    .lang-btn {
        padding: 12px 16px;
        font-size: 16px;
        min-height: 44px;
        min-width: 60px;
    }
}
```

#### 4. **CARTE - Contrôles positionnés pour desktop**
**Problème:**
- Contrôles Leaflet : top-right par défaut
- Panel de notation : `top: 80px; left: 20px; width: 300px`
- Sur mobile 375px : le panel prend **80% de l'écran**

**Impact:**
- Carte masquée par les contrôles
- Impossible de voir les pistes derrière le panel
- Navigation carte difficile

**Solution:**
```css
@media (max-width: 768px) {
    .rating-panel {
        position: fixed;
        bottom: 0;
        left: 0;
        right: 0;
        top: auto;
        width: 100%;
        max-height: 50vh;
        border-radius: 16px 16px 0 0;
        transform: translateY(100%);
        transition: transform 0.3s ease;
    }
    
    .rating-panel.show {
        transform: translateY(0);
    }
    
    /* Ajout d'un handle pour glisser */
    .rating-panel::before {
        content: '';
        display: block;
        width: 40px;
        height: 4px;
        background: #ccc;
        border-radius: 2px;
        margin: 8px auto;
    }
}
```

### P1 - IMPORTANTS (dégradation UX significative)

#### 5. **SECTIONS - Padding trop large**
**Problème:**
- `main { padding: 2rem; }` = 32px sur mobile
- `.section { padding: 2rem; }` = 32px
- Total : 64px de padding horizontal sur 375px écran
- Contenu utile : seulement **311px** (17% perdu)

**Solution:**
```css
@media (max-width: 768px) {
    main { padding: 1rem; }
    .section { padding: 1rem; }
}
```

#### 6. **TYPOGRAPHIE - Titres trop grands**
**Problème:**
- `h2 { font-size: 1.8rem; }` = 28.8px sur mobile
- Prend trop d'espace vertical
- Peut provoquer des retours à la ligne inattendus

**Solution:**
```css
@media (max-width: 768px) {
    .section h2 { font-size: 1.4rem; } /* 22.4px */
    h3 { font-size: 1.2rem; }
    h4 { font-size: 1.1rem; }
}
```

#### 7. **FORMULAIRES - Inputs non optimisés tactile**
**Problème:**
- Pas de styles spécifiques pour inputs sur mobile
- Risque de zoom automatique si font-size < 16px
- Boutons possiblement trop petits

**Solution:**
```css
@media (max-width: 768px) {
    input, textarea, select {
        font-size: 16px; /* Évite le zoom iOS */
        padding: 12px;
        min-height: 44px;
    }
    
    button[type="submit"] {
        width: 100%;
        padding: 14px;
        font-size: 16px;
        min-height: 48px;
    }
}
```

#### 8. **TOOLTIPS - Largeur fixe problématique**
**Problème:**
- `:root { --tooltip-width: 400px; }`
- Sur mobile 375px : tooltip **plus large que l'écran**
- Provoque scroll horizontal

**Solution:**
```css
@media (max-width: 768px) {
    :root {
        --tooltip-width: calc(100vw - 40px); /* 20px marge de chaque côté */
    }
    
    .leaflet-popup-content {
        max-width: calc(100vw - 60px);
    }
}
```

### P2 - AMÉLIORATIONS (confort UX)

#### 9. **ORIENTATION - Pas de styles paysage mobile**
**Recommandation:**
```css
@media (max-width: 768px) and (orientation: landscape) {
    header {
        height: 50px; /* Réduit pour gagner de la hauteur */
        padding: 0.5rem 1rem;
    }
    
    nav button {
        padding: 6px 12px;
        font-size: 14px;
    }
    
    .rating-panel {
        max-height: 70vh; /* Plus de hauteur disponible */
    }
}
```

#### 10. **INTERACTIONS TACTILES - Pas de gestures**
**Opportunités:**
- Swipe pour changer d'onglet
- Pull-to-refresh sur la carte
- Pinch-to-zoom optimisé
- Long-press pour actions contextuelles

#### 11. **PERFORMANCE - Pas d'optimisations mobile**
**Recommandations:**
- Lazy loading des images
- Réduction taille des tuiles carte
- Désactivation animations lourdes
- Service Worker pour offline

## 💡 RECOMMANDATIONS TECHNIQUES

### Architecture CSS
```css
/* Structure recommandée */
/* 1. Styles de base (mobile-first) */
body { font-size: 16px; }

/* 2. Améliorations progressives */
@media (min-width: 769px) {
    /* Tablette */
}

@media (min-width: 1025px) {
    /* Desktop */
}
```

### Approche Mobile-First
- Partir des styles mobile comme **base**
- Ajouter complexité pour écrans plus grands
- Plus maintenable à long terme
- Meilleure performance mobile

### Outils de test
- Chrome DevTools Device Mode
- Safari Responsive Design Mode
- BrowserStack (tests multi-appareils)
- Lighthouse Mobile audit
