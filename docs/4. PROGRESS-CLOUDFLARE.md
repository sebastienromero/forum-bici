#### 4.3 Si le build ÉCHOUE ❌

**Erreurs possibles et solutions :**

**Erreur 1 : "bash: build.sh: No such file or directory"**
```
Cause : Build command incorrect
Solution :
1. Retourner dans Settings → Builds & deployments
2. Build command → Changer pour : cd frontend && bash build.sh
3. Retry deployment
```

**Erreur 2 : "Directory frontend/public not found"**
```
Cause : build.sh n'a pas créé le dossier public/
Solution :
1. Vérifier que build.sh existe : git ls-files frontend/build.sh
2. Vérifier le contenu de build.sh (doit créer public/)
3. Contacter assistant pour debug
```

**Erreur 3 : "Permission denied: build.sh"**
```
Cause : build.sh n'est pas exécutable
Solution :
1. Localement : chmod +x frontend/build.sh
2. Git add + commit + push
3. Retry deployment sur Cloudflare
```

## 🚨 PLAN DE ROLLBACK (si problème majeur)

**Si à tout moment la migration Cloudflare pose problème, voici comment revenir en arrière :**

### Scénario 1 : Site Cloudflare ne fonctionne pas (build échoue)

**Symptômes :**
- Build échoue à répétition
- Site inaccessible sur pages.dev
- Erreurs 500 sur Cloudflare

**Rollback rapide (5 min) :**

1. **Réactiver Netlify immédiatement :**
   ```
   - Aller sur https://app.netlify.com
   - Site settings → Build & deploy
   - "Enable auto publishing"
   - Trigger deploy manuellement
   - Site revient en ligne en 2-3 min
   ```

2. **Debugger Cloudflare tranquillement :**
   ```
   - Lire les logs de build Cloudflare
   - Identifier l'erreur exacte
   - Demander aide à l'assistant
   - Réessayer plus tard
   ```

### Scénario 2 : Site Cloudflare fonctionne mais avec bugs

**Symptômes :**
- Site accessible mais fonctionnalités cassées
- Erreurs JavaScript
- CSS bizarre
- Supabase ne fonctionne pas

**Diagnostic avant rollback :**

1. **Vérifier que c'est bien un problème Cloudflare :**
   ```
   - Tester sur Netlify backup (si toujours actif)
   - Comparer les deux versions
   - Si Netlify OK mais Cloudflare KO → Problème Cloudflare
   ```

2. **Tentatives de fix (10 min max) :**
   ```
   - Vérifier build logs Cloudflare
   - Vérifier que tous les fichiers sont bien copiés
   - Retry deployment
   ```

3. **Si pas de solution rapide → Rollback Netlify**

### Scénario 3 : Bandwidth toujours dépassé (peu probable)

**Si même sur Cloudflare le bandwidth pose problème :**

**→ Ce n'est PAS possible avec Cloudflare (illimité)**

**Si message d'erreur quand même :**
- C'est probablement un autre problème (attaque DDoS)
- Cloudflare a des protections automatiques
- Contacter support Cloudflare (gratuit)
