# 🎯 AMÉLIORATION UX - VISION UTILISATEUR NON-TECH

**Branche :** UX-IMPROVEMENT  
**Créé le :** 9 janvier 2026  
**Objectif :** Rendre le site intuitif pour utilisateurs novices (approche 100% UX)

---

## 🎨 **VISION GLOBALE**

### Principes directeurs
1. **Onboarding** : Guider l'utilisateur dès la première visite
2. **Clarté** : Chaque action doit être évidente
3. **Feedback** : Confirmer visuellement chaque action
4. **Simplicité** : Emojis > curseurs, icônes > texte seul
5. **Mobile-first** : Penser tactile avant desktop

---

```javascript
function detectAndShowLanguageModal() {
    // Si langue déjà choisie, skip
    if (localStorage.getItem('user-language')) {
        return;
    }
    
    // Détection navigateur
    const browserLang = navigator.language.split('-')[0]; // 'es-CO' → 'es'
    
    // Si espagnol, mettre par défaut SANS modal
    if (browserLang === 'es') {
        localStorage.setItem('user-language', 'es');
        setLanguage('es');
    } 
    // Si français, mettre par défaut SANS modal
    else if (browserLang === 'fr') {
        localStorage.setItem('user-language', 'fr');
        setLanguage('fr');
    }
    // Sinon, afficher modal pour choisir
    else {
        showLanguageModal();
    }
}

// Au chargement
document.addEventListener('DOMContentLoaded', () => {
    detectAndShowLanguageModal();
    // Puis tutorial si première visite
    if (!localStorage.getItem('tutorial-completed')) {
        setTimeout(showWelcomeModal, 500);
    }
});
```

```javascript
let startY = 0;
let currentY = 0;
let isDragging = false;

const panel = document.querySelector('.rating-panel-new');

panel.addEventListener('touchstart', (e) => {
    // Only drag from handle area (top 70px)
    if (e.touches[0].clientY < panel.getBoundingClientRect().top + 70) {
        isDragging = true;
        startY = e.touches[0].clientY;
    }
});

panel.addEventListener('touchmove', (e) => {
    if (!isDragging) return;
    
    currentY = e.touches[0].clientY;
    const diff = currentY - startY;
    
    // Only allow dragging down when collapsed, or up/down when expanded
    if (diff > 0 || panel.classList.contains('expanded')) {
        e.preventDefault();
        
        // Apply transform
        const maxDrag = panel.offsetHeight;
        const dragAmount = Math.min(Math.max(diff, -maxDrag), maxDrag);
        panel.style.transform = `translateY(${dragAmount}px)`;
    }
});

panel.addEventListener('touchend', (e) => {
    if (!isDragging) return;
    
    isDragging = false;
    const diff = currentY - startY;
    
    // Snap logic
    if (Math.abs(diff) > 50) {
        if (diff > 0) {
            // Dragged down → collapse
            panel.classList.remove('expanded');
            panel.style.transform = '';
        } else {
            // Dragged up → expand
            panel.classList.add('expanded');
            panel.style.transform = '';
        }
    } else {
        // Snap back
        panel.style.transform = '';
    }
});
```
